# Elara HITL portal · clickable prototype

Mock-data prototype of the HITL portal task queue and damage labeling flow, built from the "Manya" page of the Portal Interface Figma file.

Live: https://lizco577.github.io/portal-prototype/

## Run locally

```bash
npm install
npm run dev
```

Vite + React + TypeScript + Tailwind + shadcn/ui. Hash routing so it works on GitHub Pages. Every push to `main` deploys through `.github/workflows/deploy.yml`.
